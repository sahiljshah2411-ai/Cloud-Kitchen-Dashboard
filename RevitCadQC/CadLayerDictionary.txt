# Revit CAD QC - layer dictionary
# What every CAD layer is. Edit in Notepad, no rebuild needed.
# Your copy wins:  %APPDATA%\RevitCadQC\CadLayerDictionary.txt
# Shipped copy:    next to CadQC.Revit.dll (used when yours does not exist)
# Bad/missing file = built-in rules from the QC settings.
#
# <CATEGORY>=<regex>|<regex>|...        (case-insensitive)
# Categories: IGNORE WALL DOOR WINDOW COLUMN GRID ROOM DIMENSION ANNOTATION
#
# ORDER MATTERS - FIRST MATCH WINS. Specific rules before generic ones:
#   "A-WALL-PATT" must hit IGNORE (hatch) before WALL,
#   "A-DOOR-WALL" must hit DOOR before WALL,
#   "COL-HATCH" must hit IGNORE before COLUMN.
#
# A consultant profile (layer review grid, saved once per consultant in
# %APPDATA%\RevitCadQC\CadProfiles) overrides this file for exact layer names.

# ---- never read ----
IGNORE=HATCH|PATT|POCHE
IGNORE=FURN|FURNITURE|FIXTURE|SANITARY|PLUMB|ELEC|HVAC|MEP|LIGHTING
IGNORE=FLOOR.?PATT|FLOORING|TILE|PAVING|LANDSCAPE|TREE|PLANT|CAR\b|VEHICLE
IGNORE=TITLE|BORDER|SHEET|VIEWPORT|VPORT|DEFPOINTS|NPLT|NO.?PLOT|REVISION|CLOUD
IGNORE=XREF.?TEMP|TEMP|CONSTR|CONST.?LINE

# ---- walls ----
